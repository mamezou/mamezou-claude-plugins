# AWS構成図確認チェックリスト

`aws-guide.md` に沿って作図したあと、PNGを書き出してから目視で確認する。

## 構成

- [ ] 図の目的がタイトルとサブタイトルから分かる
- [ ] AWSアカウントとリージョンが必要に応じて明記されている
- [ ] AWS Cloud、リージョン、VPC、サブネットなどの境界が実構成と一致している
- [ ] リージョンサービスをVPCやサブネット内へ誤配置していない
- [ ] AWS外部のサービスがAWS Cloud境界の外側にある
- [ ] 対象外の経路や未決定事項が事実と区別されている

## アイコンと名称

- [ ] 作成時点のAWS Architecture Iconsを使用している
- [ ] アイコンの縦横比を変更していない
- [ ] 同じ階層のアイコンサイズがそろっている
- [ ] AWS公式アイコンを切り抜き、反転、回転していない
- [ ] AWSサービス名を公式名称で記載している
- [ ] 汎用図形をAWSサービスの代用として使用していない
- [ ] 主要なAWSサービスとAWSリソースに公式アイコンがある
- [ ] AWSサービスを示す箱が文字だけになっていない
- [ ] 複数サービスをまとめた箱に、識別に必要な公式アイコンがある
- [ ] 構成に存在しないアイコンを装飾目的で追加していない

## 色と外観

- [ ] 各AWS公式アイコンの色が、AWS公式ツールキットのサービスカテゴリ色と一致している
- [ ] 各AWS公式グループの境界、グループアイコン、見出し文字が、AWS公式ツールキットのグループ色と一致している
- [ ] Draw.ioの`fillColor`、`strokeColor`、`fontColor`を、AWS公式ツールキットと照合している
- [ ] 既存・新設などの状態を表す目的で、AWS公式アイコンやAWS公式グループの色を変更していない
- [ ] サービス説明枠が、白背景、直角、グレーの細線になっている
- [ ] 色付きの角丸枠と同系色の薄い背景を組み合わせたカードを図全体へ反復していない
- [ ] 色で意味を補助する場合、名称、状態名、線種または凡例がある
- [ ] 色の使い方が図内で一貫している
- [ ] 注意事項が`注記：`などの見出しを付けた通常テキスト、または番号付きコールアウトになっている
- [ ] 注記の左側に縦線や色帯がない

## 接続

- [ ] 実線と破線の意味が図内で一貫している
- [ ] 接続線が直線と直角を基本としている
- [ ] すべての矢印の向きが処理方向と一致している
- [ ] 矢印ラベルが線や要素と重なっていない
- [ ] 線の交差が必要な範囲に抑えられている
- [ ] 複数の線種を使用する場合に凡例がある

## フォント

- [ ] `fc-match <フォント名>`で指定したフォント(既定はIPAPGothic)が解決される
- [ ] タイトル、本文、境界名、注記、矢印ラベルに同じ`fontFamily`が指定されている
- [ ] 1つの図の中で別のフォントが混在していない
- [ ] PNG書き出し後の字形、改行位置、文字幅がDraw.io元データと一致している

## PNG確認

- [ ] 指定したページサイズで書き出されている
- [ ] タイトル、本文、注記、凡例に文字切れがない
- [ ] アイコン、枠、矢印、ラベルに重なりがない
- [ ] 100%表示で主要な文字を読める
- [ ] AWS公式アイコンの色と縦横比が保たれている

## 公開前

- [ ] 図の中にローカルパス、社内ホスト名、個人名が入っていない
- [ ] 顧客名・固有リソース名を匿名化している
