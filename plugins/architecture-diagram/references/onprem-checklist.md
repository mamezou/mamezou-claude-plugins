# オンプレミス・自宅ネットワーク構成図確認チェックリスト

`onprem-guide.md` に沿って作図したあと、PNGを書き出してから目視で確認する。

## 構成

- [ ] 図の目的がタイトルとサブタイトルから分かる
- [ ] 枠にした入れ子が1系統で、枠が交差していない
- [ ] セグメントの枠に、名称、VLAN ID、サブネット、ゲートウェイが書いてある
- [ ] セグメントの枠と機器の所属が、稼働中のスイッチとルーターから取得した設定と一致している
- [ ] 複数のセグメントに接続する機器が、セグメントの枠の外にあり、各セグメントへ線で結ばれている
- [ ] 構成にないセグメントや、役割で作った枠がない
- [ ] ルーティング、NAT、DHCP、DNSを担当する機器が、ラベルから分かる
- [ ] 回線からインターネットまでの経路がつながっている
- [ ] 拠点外から拠点内へ入る経路が、すべて描かれている
- [ ] 拠点外の端末とサービスが、拠点の枠の外側にある
- [ ] 物理ホストの管理インターフェイスが、所属するセグメントの枠の中に、アイコンのない箱で描かれている
- [ ] 撤去予定の機器や作業中の状態が描かれていない

## アイコンと名称

- [ ] 物理機器にCisco19、VMware環境の仮想マシンに `mxgraph.vvd.virtual_machine` を使い、ほかのセットを混ぜていない
- [ ] VMware以外の仮想化基盤の仮想マシンが、ラベルの先頭に `VM` と書いた箱で描かれている
- [ ] Cisco19の図形名が現行のパレットの名前(`wireless_access_point2` など)で、旧図形が使われていない
- [ ] 対応するアイコンがない機器を、別の機器のアイコンで代用せず、箱で描いている
- [ ] アイコンのラベルが、役割、型番またはホスト名、IPアドレスの順になっている
- [ ] アイコンの縦横比を変更していない
- [ ] 同じ階層のアイコンサイズがそろっている
- [ ] 構成に存在しないアイコンを装飾目的で追加していない

## 色と外観

- [ ] 内蔵アイコンの既定の色を変更していない
- [ ] 枠を白背景と枠線で描き、枠内へ背景色を敷いていない
- [ ] セグメントの枠、拠点の枠、トンネル、通信の流れ、遮断の色が `onprem-guide.md` の基本色と一致している
- [ ] 信頼度や稼働状態を色で表していない
- [ ] 色付きの角丸枠と同系色の薄い背景を組み合わせたカードを図全体へ反復していない
- [ ] 注記が `注記:` などの見出しを付けた1行の通常テキストになっている
- [ ] 注記の左側に縦線や色帯がない

## 接続

- [ ] 有線、無線、仮想スイッチ経由の接続の線に矢印がなく、トンネルと通信の流れの線にだけ矢印がある
- [ ] スイッチのポートにつながる有線のラベルに、ポート、アクセスまたはトランクの別、VLAN IDが、スイッチの設定どおりに書いてある
- [ ] トンネルの線が、拠点外の端末または中継サービスから拠点内の終端へ引かれ、矢印が到達先を向き、方式の名称が書いてある
- [ ] 物理ホストと各セグメントを結ぶ線が、有線と別の線種(グレーの破線)で、仮想スイッチであることを示すラベルが1か所ある
- [ ] 同じセグメントの枠の中では、経由する機器を示す場合を除き、機器どうしを線で結んでいない
- [ ] 遮断する経路が赤の破線で、終端が×印になっている
- [ ] 接続線が直線と直角を基本としている
- [ ] 線の交差が必要な範囲に抑えられている
- [ ] 凡例に、使用した線種、物理機器と仮想マシンのアイコン、セグメントの枠がある

## フォント

- [ ] `fc-match <フォント名>` で指定したフォント(既定はIPAPGothic)が解決される
- [ ] タイトル、本文、枠の名称、注記、線のラベルに同じ `fontFamily` が指定されている
- [ ] PNG書き出し後の字形、改行位置、文字幅がDraw.io元データと一致している

## PNG確認

- [ ] 指定したページサイズで書き出されている
- [ ] タイトル、ラベル、注記、凡例に文字切れがない
- [ ] アイコンのラベルが、隣のラベル、線のラベル、枠線と重なっていない
- [ ] 100%表示で主要な文字を読める
- [ ] 使用した内蔵アイコンがすべて描画されている

## 公開前

- [ ] 公開する図、社外へ出す図に、顧客名、固有の拠点名や機器名、グローバルIPアドレス、MACアドレス、SSID、住所や設置場所、個人名、取得済みのドメイン名が入っていない
- [ ] 公開する図、社外へ出す図のプライベートIPアドレスとホスト名を、例示用の値に置き換えている
- [ ] 図の中にローカルパスが入っていない
