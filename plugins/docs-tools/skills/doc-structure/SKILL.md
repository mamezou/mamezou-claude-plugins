# 資料の構成の作り方

読み手が判断か作業に使える資料を作る。「何を載せるか」より先に「誰が何を決め、何をする資料か」を決める。

載せる中身の一覧は `/docs-tools:doc-draft`、文の検査は `/docs-tools:draft-precheck` が行う。この Skill は、載せる中身を章へ割り当てる骨子と、書いた後の章立てだけを扱う。スライドでは、ページの見た目も扱う。

docs-tools が無いとき、または載せる中身の一覧が無いときは、元の資料と依頼の原文から、載せる論点を1行ずつ書き出して一覧にする。既存の資料を直すときは、既存の資料の節を1行ずつ書き出して一覧にする。

## 使い分け

| 依頼 | 行う手順 |
|---|---|
| 新しく作る、全面的に書き直す | 1から10の全部 |
| 既存の資料の構成をレビューする | 1と2を資料から読み取り、8と9を行い、10で指摘を伝える。骨子の作成、依頼者への骨子の確認、本文の修正は行わない |
| 既存の資料の構成を直す | 1から6を既存の資料に対して行い、7で直す前と直した後の骨子を見せる。以降は同じ |
| スライドを作る、直す、レビューする | 上の3つの行のどれかに従う。手順1、5、6、7、8、10で、資料の種類に加えてスライドの決まりを使う |

## 手順

1. 資料の種類を1つ決める。判断を求める資料、設計の記録、手順書、説明の資料のどれか。2つに当たるときは、資料を分ける。スライドのときは、見せる資料か配る資料かも1つに決める
2. 読み手を決める。読み手が読む前に知っていること、読んだ後に決めること、行うことを書く。決まらなければ依頼者に聞く。推測で書かない
3. 決めることの一覧を作る。手順書では作業の一覧、設計の記録では対象の一覧、説明の資料では読み手の問いの一覧にする。一覧の母集団にした正本の名前を書く
4. 範囲外を書く。読み手が載っていると期待するが扱わないことと、行わないこと
5. `${CLAUDE_SKILL_DIR}/assets/` の種類ごとの骨子の型を複製し、章を切る。載せる中身の一覧の各行を、章へ1か所ずつ割り当てる。割り当て先が無い行は、章が足りないのか、どの判断にも作業にも使わない行なのかを分ける。前者は章を足す。後者は参考情報へ送る。載せると決めた行を外すときは、手順7で依頼者に聞く。スライドのときは、種類の型の「資料の前提」と冒頭の一覧だけを埋め、骨子の表の代わりに `${CLAUDE_SKILL_DIR}/assets/outline-slides.md` の全体図とページの表を作る。載せる中身の一覧の各行は、ページへ1か所ずつ割り当てる。分量の目安は、部ごとのページの数で書く
6. 種類ごとのチェックリストのうち、【骨子】の印の項目で骨子を点検する。当てはまらない項目は「対象外」と理由を書き、確認できなかった項目は「未確認」と書く。スライドのときは、`${CLAUDE_SKILL_DIR}/references/slides-checklist.md` の【骨子】の項目でも点検する
7. 骨子の表を依頼者に見せる。載せる中身の一覧と一緒に、1回で聞く。答えが出るまで本文を書かない。スライドのときは、全体図とページの表を見せる
8. 本文を書いた後、スライド以外は `python3 "${CLAUDE_SKILL_DIR}/scripts/outline-check.py" <資料> --type <種類>` を実行し、当たりを1件ずつ現物で判定する。スライドは、このスクリプトが Markdown の見出しを読むもので使えないため、全部のページの題と現在地の印を順に書き出す。PowerPoint と PDF は、ページごとの文字を取り出して書き出す。続けて、種類のチェックリストの全部の項目と、スライドのときは slides-checklist.md の全部の項目で本文を点検する
9. 仕上げに、別のモデルのレビューを通す。手順は `${CLAUDE_SKILL_DIR}/references/cross-review.md` に従う。CLI が無い、送ってよい資料か決まっていない、実行が失敗した、のどれかのときは、レビューを行わずに進め、行っていないことと理由を手順10で伝える
10. 完了時に依頼者へ伝える。資料の種類、骨子の表、母集団の正本と照らした結果、スクリプトの当たりのうち残したものと理由、別のモデルの指摘の採否、確認していない事項。スライドのときは、骨子の表に代えて全体図とページの表を示し、スクリプトの当たりに代えて、スクリプトを使っていないことと、ページの題を並べた一覧を伝える

## ルール

章の切り方

- 章は、資料の種類の単位で切る。判断を求める資料は決めること1つに章1つ、手順書は作業1つに章1つ、設計の記録は対象の構造、説明の資料は読み手の問い1つに章1つ
- 題の主題は1つにする。1つの主題の下に、決めることが複数あってよい
- 冒頭に、答えと一覧を置く。一覧の項目ごとに章を1つ作り、章の題に一覧の呼び名の語を入れ、一覧と同じ順に並べる。前提、確認、元に戻す方法、全体の構成、参考情報、用語、出典など、種類の型にある共通の章は、一覧と対応させない
- 1つの判断に使う材料は、1つの章に集める。章の1文目に推奨を1文で書き、続けて、比較の基準、選択肢の比較、推奨の理由、選んだ結果として起きることの順にする。選択肢に現状のままの案を入れる
- 同じ事柄と同じ数値の置き場所は、冒頭の一覧を除いて、1つの章にする。1つの章の中でも、3つ以上の節に書かない
- 一覧と表には母集団を決める。母集団の各項目は、対象、対象外、行わない、のどれかで資料に出す
- 同じ階層の章、節、表の行は、1つの切り口で分ける。切り口の名前を書き、全部の項目がその切り口の値になっているかを見る。例: 切り口が「障害の種類」なら、項目は全部、障害の種類の名前になる。「監視」が混ざっていれば当たり
- 同じものは同じ呼び名で書く

読む順と量

- 判断を求める資料と説明の資料は、章の1文目に章の結論を書き、表と箇条書きをその結論の根拠に限る。手順書の手順と期待結果、設計の記録の設定値の表は、資料の中身そのものなので、この決まりの対象外
- 章の順と、章の中の項目の順は、時間、構造、重要度のどれか1つにする。一般の話を先に、例外と条件を後にする
- 本文は、読み手の判断か作業を変える中身に限る。判断も作業も変えない計算の内訳、例外、経緯、用語は、末尾か別の資料に置く。作業の条件を変える例外と注意は、当たる手順の直前に書く
- 章ごとの分量の目安を骨子に書く。本文の章が4つ以上あって、1つの章が本文の4割を超えたら、その章に複数の判断か種類が入っていないかを読む。入っていれば章を分ける。字数は、用語と出典と参考情報を除き、コードを含めて数える
- 見出しは、判断か対象か作業の名前にする。括弧の注記を付けない。「背景」「一覧」「その他」「補足」のような入れ物の名前にしない

スライドの形式

- 依頼者が形式を決めていないときは、スライドを、その場で相手に働きかけるか、反論にその場で答える必要があるときだけに使う。それ以外の用途なら、文書で足りないかを手順7で一緒に聞く。依頼者がスライドと決めているときは聞かない
- 見せる資料か配る資料かを1つに決める。両方に使うときは、資料を2つに分けるか、見せる資料を先に作り、配る資料の文をノートに書く
- 配る資料は、説明する人がいなくても題と本文で結論が分かるようにする。見せる資料は、文を詰め込まない
- 見せる資料のページの数は、話す時間に合わせて決める

スライドの全体と部分

- 種類の決まりの「章」を「部」と読み替える。部は、種類の一覧の項目1つに当たるページのまとまりにし、種類の一覧の順に並べる。全体図には、各項目を扱う部の番号を書く
- 最初の全体、部分、最後の全体の順にする。最初の全体は、母集団の全部の項目を、対象、対象外、行わない、で分けた全体図にする。全体図の母集団の正本は、機能の説明なら全部の機能を確かめられる要件定義か機能の一覧にし、問いの一覧の正本とは分けて書く
- 全体図は、要約ではなく枠組みにする。区分と全部の項目の名前を見せ、数値と細部は部分のページに回す。最初の全体を省かない。1ページに入りきらないときは、区分だけの総覧のページを置き、続けて区分ごとの項目のページを置く
- 全体図を読むのに要る語は、全体図のページか、その直前のページで説明する。この語には、用語を末尾に置く決まりを当てない。ほかの語は、種類の決まりどおり末尾に置く
- 部分のページに、全体図の縮小と現在地の印を置き、今の部の区分を目立たせる。例: 今の区分だけを色で示し、ほかの区分は灰色にする。現在地の印には、全体図と同じ部の呼び名と番号を書く
- 全体図の対象の項目ごとに、説明するページの番号を骨子に書き、対応するページが無い項目を残さない。全体図に無いページを作らない
- 種類の型にある共通の章は、共通のページとして置く。例は前提、停止条件、元に戻す方法、用語、出典。全体図には、共通のページを母集団の項目と分けて書く。全体図に無いページを作らない決まりは、共通のページには当てない
- 付録を除く本文の最後のページは、最初と同じ全体図にする。最後の全体には、全体図の項目と、部分で述べた結論だけを載せる。最後の全体には、同じ事柄を1か所に置く決まりと、末尾にまとめの章を置かない決まりを当てない
- 質問や依頼は、選んだ資料の種類で認められ、依頼者が必要としているときだけ載せる。載せるときは、最後の全体図の該当する項目に添える

スライドのページ

- 判断を求める資料と説明の資料では、1枚に結論を1つ置き、ページの題を結論の文にする。資料の題と部の名前は、今までどおり名前にする。手順書と設計の記録のページの題は、作業か対象の名前にする
- 答えを後のページに回すときは、どのページで答えるかを先に書く
- 項目を並べるページは、題に項目の数を入れる。例: 「移行の課題は2つです」
- 1枚に置く図と表は、合わせて2つまでにし、題の裏付けに要るものだけを載せる。収まらなければページを分ける
- 本文の図、表、画面は、題の裏付けに限る。裏付けにならないページと要素は、消すか、まとめるか、付録へ移す
- ページの題だけを順に読んで、話の筋が通るようにする。題の数とほぼ同じ数の文で、資料の筋を言えるようにする
- 冒頭の一覧の各項目は、後のページの題と同じ順で対応させる
- 画面の写真は必要な部分だけを切り抜き、説明の文と番号は写真の該当する箇所の隣に置く
- 引用した数値、図、画面には出典を書く

スライドの見た目

この節の決まりは、ページを作った後に確かめる。

- 同じ情報は近づけ、違う情報は離す。読む順は上から下、左から右にし、ページの中に要素を散らさない
- 並びの型を、中身の種類に合わせて選び、資料の中で同じ型を繰り返す。例: 並列はカード、対応は表、時の順は時間の軸、数値は大きな数字
- 色は、ベース、メイン、アクセントの3色程度にする。アクセントの色は、目立たせたい所だけに使う。赤と緑のように見分けにくい組み合わせで区別しない
- 題、小見出し、本文の文字の大きさに、はっきり差を付ける。見せる資料の本文は28ポイント以上にする
- 資料の全体で、同じ配置と色を繰り返す。中身に関係の無い飾り、ロゴ、画像を置かない

## 型どおりに作ると出る構成の癖と直し方

| 癖 | 直し方 |
|---|---|
| 目的、前提、現状、対策、まとめの順の章立て | 決めること1つに章を1つ当てる |
| 冒頭に判断の名前だけを並べ、案と判断の材料は末尾の「判断が必要な事項」に置く | 案、判断の材料、期限を付けた一覧を冒頭に置き、末尾の章を無くす |
| 複数の判断の比較、どの案でも同じ対策、対象外の話を「対策」の1つの章に入れる | 判断ごとの章に分け、どの案でも同じ対策と対象外の話は前提の章へ移す。1つの章の表は、列の組を3種類までにする |
| 同じ数値を、比較の表、推奨の節、判断の一覧で書く | 正とする場所を1つ決める |
| 推奨の理由の節が、比較の節より前にある | 章の1文目に推奨を1文で書き、理由は比較の後に書く |
| 「参考情報」に本題が入っている | 該当する判断の章か前提へ移す |
| 行わないことを書かない | 前提の章に、行わないことの一覧を置く |
| 手順書に、案の比較と、決まった判断の記録が入っている | 案の比較は設計の記録へ、判断の記録は台帳へ移し、手順書には決まった内容だけを書く |
| 題に主題が2つある。例は「構成要素の一覧と、調整の案」 | 資料を2本に分ける。1つの主題の下の複数の判断は、1本でよい |
| 章が、見出しの直後に表か節で始まる | 章の結論を1文で書く |

AI が作った資料の判定基準ではない。読み手を決めずに書くと、人の資料にも出る。

## 骨子を作らせる指示の型

```text
<題>の骨子を作ってください。本文は書かないでください。

資料の種類: <判断を求める資料 / 設計の記録 / 手順書 / 説明の資料>
読み手: <誰が読むか。読む前に知っていること>
読んだ後にすること: <決めること、行うこと>

決めることの一覧(手順書は作業、設計の記録は対象、説明の資料は問い):
- <項目。案、判断の材料、期限>

母集団の正本: <一覧の項目を取った資料>
範囲外: <読み手が期待するが扱わないこと、行わないこと>
載せる中身の一覧: <doc-draft の一覧の「載せる」の行>

返すもの: 種類の骨子の型(assets/)の「骨子の表」と同じ列の表。
章へ割り当てられなかった中身と、2つの章に割り当てたくなった中身の一覧。
```

## 確認

- [ ] 資料の種類が1つで、題の主題が1つ
- [ ] 題、見出し、各章の1文目だけを読んで、読み手が何をする資料かを言える。判断を求める資料は推奨、手順書は作業の順、設計の記録は対象の範囲、説明の資料は問いへの答え
- [ ] 冒頭の一覧の各項目に、呼び名の語を題に含む章が1つずつ、一覧と同じ順である
- [ ] 同じ数値が、冒頭の一覧を除いて2つ以上の章に出ていない。出ていれば、別の事柄の数値である
- [ ] 母集団の正本と照らし、各項目が対象、対象外、行わない、のどれかで出ている
- [ ] 同じ階層の見出しを並べ、切り口の名前を書ける。全部の見出しが、その切り口の値になっている
- [ ] 消しても読み手の判断と作業が変わらない章、節、表、列が無い
- [ ] 本文の章が4つ以上あるとき、本文の4割を超える章に、複数の判断か種類が入っていない
- [ ] スライドのとき、目的のページの次の全体図に、母集団の全部の項目が、対象、対象外、行わない、のどれかで出ていて、付録を除く本文の最後のページが同じ全体図に戻る
- [ ] スライドのとき、ページの題だけを順に読んで話の筋が通る
