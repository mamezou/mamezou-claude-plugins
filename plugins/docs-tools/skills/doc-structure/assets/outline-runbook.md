## 骨子の表

| 章 | 中身 | 作業 | 分量の目安 |
|---|---|---|---|
| 冒頭 | 対象、実施者、アクセス手段、所要時間の目安、完了の条件。作業の一覧 | 全部 | <字> |
| 1. 前提 | 作業を始める前に満たす状態。確認の方法 | なし | <字> |
| 2. 停止条件 | 作業を止める条件。元に戻せない操作の名指し | なし | <字> |
| 3. <作業1の呼び名> | 理由の1文。手順ごとに、実施者、アクセス手段、コマンドか画面の操作、期待結果、違ったときに止めるか戻すか再開するか | 1 | <字> |
| 4. <作業2の呼び名> | <同じ型> | 2 | <字> |
| 5. 確認 | 変更の後に、読み取りで確認する手順と期待結果 | なし | <字> |
| 6. 元に戻す方法 | 作業ごとの戻し方。戻せない作業は、戻せないと書く。戻す手順が失敗したときの連絡先 | なし | <字> |
| 出典 | 正本、関連する手順書、公式の資料のリンク | なし | <字> |
