# 判断を求める資料のチェックリスト

検討資料、提案、方式の比較など、読み手に決めてもらう資料に使う。【骨子】の印の項目は、骨子を作った後と本文を書いた後の2回確認する。印の無い項目は、本文を書いた後に確認する。当てはまらない項目は「対象外」と理由を書き、確認できなかった項目は「未確認」と書く。

## 冒頭

- [ ] 【骨子】題の主題が1つで、何の判断かが分かる
- [ ] 【骨子】決めることの一覧が冒頭にあり、番号が付いている
- [ ] 【骨子】一覧の各項目に、案、判断の材料、期限の3つがある
- [ ] 【骨子】一覧の各項目の案が1つで、推奨になっている
- [ ] 1文目が、何を決めるための資料かを述べている
- [ ] 題と一覧の間に、経緯と、仕組みの説明が無い

## 前提の章

- [ ] 【骨子】検討の対象と対象外を、表か一覧で書いている
- [ ] 【骨子】行わないこと、作らないものを書いている
- [ ] 【骨子】判断どうしに依存があるとき、どの判断の結果が、どの判断の前提になるかを書いている
- [ ] 【骨子】前提の章に、1つの判断にだけ使う比較が入っていない

## 判断の章

- [ ] 【骨子】決めること1つに章が1つあり、章の題に冒頭の一覧の呼び名の語がある
- [ ] 【骨子】判断の章の順が、冒頭の一覧の順と同じ
- [ ] 【骨子】選択肢に、現状のままの案がある
- [ ] 【骨子】選択肢の数が5つ以下
- [ ] 章の1文目が、推奨と理由を1文で述べている
- [ ] 比較の基準を、比較の表の前に書いている
- [ ] 比較の表の列が基準で、全部の選択肢に全部の列の値がある
- [ ] 必須の条件を満たさないために比較から除いた案があるとき、案の名前と、満たさない条件を書いている
- [ ] 費用を比べる表に、基準の額か基準を書いた場所、増加額、増加率がある。基準の額が0円のときは、増加率を「なし」と書く
- [ ] 推奨の理由の説明が、比較の表の後にある
- [ ] 選んだ結果として起きることを書いている。良いことと悪いことの両方
- [ ] 後から変えられない選択に、変えられない理由と期限を書いている
- [ ] 1つの章の表の、列の組が3種類以下

## 重なりと抜け

- [ ] 同じ数値が、冒頭の一覧を除いて2つ以上の章に出ていない。出ていれば、別の事柄の数値である
- [ ] 同じ数値が、1つの章の3つ以上の節に出ていない
- [ ] 同じ判断の推奨を書いた場所が、冒頭の一覧と、その判断の章の2か所まで
- [ ] 【骨子】一覧の母集団の正本の名前を、骨子に書いた
- [ ] 【骨子】母集団の各項目が、対象、対象外、行わない、のどれかで資料に出ている
- [ ] 【骨子】打ち合わせの記録があるとき、記録にある議題が資料に出ている

## 末尾

- [ ] 【骨子】「判断が必要な事項」「まとめ」の章が末尾に無い
- [ ] 【骨子】参考情報に、どの判断にも使わない中身だけがある
- [ ] 【骨子】金額の前提、計算の内訳、用語、出典が末尾にある
- [ ] 依頼、日程、作業の予定が本文に無い
