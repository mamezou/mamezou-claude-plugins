# 説明の資料のチェックリスト

仕組み、方針、調査の結果など、読み手が理解するための資料に使う。【骨子】の印の項目は、骨子を作った後と本文を書いた後の2回確認する。印の無い項目は、本文を書いた後に確認する。当てはまらない項目は「対象外」と理由を書き、確認できなかった項目は「未確認」と書く。

## 冒頭

- [ ] 【骨子】題の主題が1つ
- [ ] 【骨子】読み手の問いの一覧が冒頭にあり、問いごとに答えが1文である
- [ ] 【骨子】問いの一覧の母集団を書いている。依頼の原文、読み手から届いた質問など
- [ ] 1文目が、読み手のどの問いに答える資料かを述べている
- [ ] 問いの一覧より前に、答えを述べる文がある
- [ ] 読み手が読む前に知っていることを、説明していない

## 章

- [ ] 【骨子】読み手の問い1つに章が1つあり、章の題に、問いの一覧の問いの語がある
- [ ] 【骨子】章の順が、問いの一覧の順と同じで、一般の話から例外と条件へ進む
- [ ] 【骨子】後の章を読まないと分からない章が、前に無い
- [ ] 【骨子】例外と条件の章の各項目に、どの問いの例外かを書いている
- [ ] 章の1文目が、問いへの答え
- [ ] 構成要素どうしの接続か、処理の流れを説明する章に、図がある

## 置かないもの

- [ ] 【骨子】読み手への依頼、判断のお願いが無い。あれば、判断を求める資料へ分ける
- [ ] 【骨子】作業の手順が無い。手順書へリンクする
- [ ] 調査の経緯が無い。分かったことだけを書いている
- [ ] 確認していないことを、事実として書いていない
