# 設計の記録のチェックリスト

構成、設定値、決まった方式など、読み手が調べるための資料に使う。【骨子】の印の項目は、骨子を作った後と本文を書いた後の2回確認する。印の無い項目は、本文を書いた後に確認する。当てはまらない項目は「対象外」と理由を書き、確認できなかった項目は「未確認」と書く。

## 冒頭

- [ ] 【骨子】題が、対象の名前1つになっている
- [ ] 【骨子】対象の一覧が冒頭にある。構成要素、環境、設定の区分など
- [ ] 【骨子】記録の対象外を書いている
- [ ] 【骨子】どの環境の、どの版か時点の記録かを書いている
- [ ] 1文目が、何の、どの範囲の記録かを述べている

## 章

- [ ] 【骨子】対象ごとの章を、対象の構造で切っている。構成要素ごと、層ごと、環境ごとのどれか1つ
- [ ] 【骨子】対象ごとの章の順が、対象の構造の順。通信の流れの順、上の層から下の層の順など
- [ ] 【骨子】対象ごとの章の全部に、同じ項目が同じ順である。用途、設定値、理由など。全体の構成、作らないもの、出典の章は除く
- [ ] 【骨子】一覧の行が、母集団の正本の全部の項目と対応している
- [ ] 【骨子】作らないもの、設定しないものを、行か一覧で書いている

## 中身

- [ ] 【骨子】未決の案が無い。未決の案は、判断を求める資料へ分ける
- [ ] 【骨子】作業の手順、調整の案、依頼、費用の比較が無い
- [ ] 値に、理由を1つ添えている
- [ ] 表のセルが、名詞句1つか2つ
- [ ] 経緯、決めた日、決めた場を本文に書いていない。台帳か出典へ送る

## 重なりと抜け

- [ ] 同じ設定値を、2つ以上の章に書いていない
- [ ] 【骨子】母集団の正本の名前と、正本の環境と版か時点を、出典に書いている
- [ ] 正本と食い違う値が無い。照らした正本の版か時点が、記録の対象と同じ
- [ ] 出典と、ほかの資料へのリンクを開いて、指す場所があることを確認した
