# 手順書のチェックリスト

読み手が作業を行うための資料に使う。【骨子】の印の項目は、骨子を作った後と本文を書いた後の2回確認する。印の無い項目は、本文を書いた後に確認する。当てはまらない項目は「対象外」と理由を書き、確認できなかった項目は「未確認」と書く。

## 冒頭

- [ ] 【骨子】題が、作業の名前1つになっている
- [ ] 【骨子】冒頭に、対象、実施者、アクセス手段、所要時間の目安がある
- [ ] 【骨子】作業の一覧が冒頭にあり、行う順に番号が付いている
- [ ] 【骨子】対象外の作業を書いている
- [ ] 【骨子】作業の全体が終わったと言える条件を書いている

## 手順の前に置く章

- [ ] 【骨子】前提の章が、手順の章の前にある
- [ ] 【骨子】停止条件の章が、最初の操作より前にある
- [ ] 【骨子】元に戻せない操作を、手順の前に名指ししている
- [ ] 前提を、コマンドか画面で確認できる状態として書いている

## 手順の章

- [ ] 【骨子】作業1つに章が1つあり、章の題に冒頭の一覧の呼び名の語がある
- [ ] 【骨子】章の順が、作業を行う順
- [ ] 【骨子】実施の時期が違う作業を、同じ章に入れていない
- [ ] 各手順に、実施者、アクセス手段、コマンドか画面の操作、期待結果がある。実施者とアクセス手段が冒頭と同じときは、省いてよい
- [ ] 期待結果と違ったときに、止めるか、戻すか、どの手順から再開するかを書いている
- [ ] 元に戻す手順が失敗したときの連絡先を書いている
- [ ] 承認が要る操作の直前に、誰の承認が要るかを書いている
- [ ] 別の手順書を指して終わる手順が無い
- [ ] 作業の理由を、章の最初に1文で書いている
- [ ] 作業の条件を変える例外と注意を、当たる手順の直前に書いている

## 手順の後に置く章

- [ ] 【骨子】変更の後に結果を確認する手順が、変更の手順と別の章にある
- [ ] 【骨子】元に戻す方法が、作業ごとにある。戻せない作業は、戻せないと書いている

## 置かないもの

- [ ] 【骨子】案の比較が無い。決まった内容だけを書いている
- [ ] 決まった判断の記録、依頼者への確認点、進み具合を書いた行が無い
- [ ] 決めた日、作成の経緯など、日付のある経緯が無い。操作の条件と期待結果に要る日付は残す
- [ ] 見出しに括弧の注記が無い
