# スライドのチェックリスト

PowerPoint、Google スライド、Keynote、HTML や PDF のスライドなど、ページに分けた資料に使う。資料の種類のチェックリストと一緒に使う。各項目は、SKILL.md のスライドのルールと同じ順で、1つずつ対応する。

種類のチェックリストの項目のうち、次のものはスライドでは当てない。最後の全体には、同じ事柄を1か所に置く項目と、末尾にまとめの章を置かない項目を当てない。全体図を読むのに要る語には、用語を末尾に置く項目を当てない。

【骨子】の印の項目は、骨子を作った後と本文を書いた後の2回確認する。印の無い項目は、ページを作った後に確認する。当てはまらない項目は「対象外」と理由を書き、確認できなかった項目は「未確認」と書く。決まりの根拠と出典は `principles.md` の「スライドに足す決まり」にある。

## スライドの形式

- [ ] 【骨子】依頼者が形式を決めていないとき、その場で相手に働きかけるか、反論にその場で答える用途でなければ、文書で足りないかを手順7で一緒に聞いた。依頼者がスライドと決めているときは対象外
- [ ] 【骨子】見せる資料か配る資料かを1つに決めた。見せる資料は、人が話しながら映す。配る資料は、読み手が1人で読む。両方に使うときは、資料を2つに分けたか、見せる資料を先に作り、配る資料の文をノートに書いた
- [ ] 配る資料では、説明する人がいなくても、題と本文だけで結論が分かる。見せる資料では、文を詰め込んでいない
- [ ] 【骨子】見せる資料のページの数が、話す時間に合っている

## スライドの全体と部分

- [ ] 【骨子】種類の一覧の項目ごとに部が1つあり、部が種類の一覧の順に並んでいる。全体図に、各項目を扱う部の番号がある
- [ ] 【骨子】表紙と冒頭の一覧のページの次に、全体図のページがある。全体図を読むのに要る語の説明のページは、その間にあってよい。全体図に、母集団の全部の項目が、対象、対象外、行わない、のどれかで載っている。全体図の母集団の正本の名前を、問いの一覧の正本とは分けて書いた。全体図の区分の切り口が1つで、名前を書ける
- [ ] 【骨子】全体図が要約ではなく枠組みになっている。区分と全部の項目の名前を見せ、数値と細部は部分のページに回している。1ページに入りきらないときは、区分だけの総覧のページがあり、続けて区分ごとの項目のページがある
- [ ] 【骨子】全体図を読むのに要る語を、全体図のページか、その直前のページで説明している
- [ ] 部分のページに、全体図の縮小と現在地の印があり、今の部の区分が目立っている。現在地の印の部の呼び名と番号が、全体図と同じ。表紙、目的、全体図、共通、最後の全体のページは除く
- [ ] 【骨子】全体図の対象の各項目に、説明するページの番号があり、対応するページが無い項目が無い。全体図に無いページが無い。例は番号の外の案、全体図に無い機能
- [ ] 【骨子】種類の型にある共通の章が、共通のページとして置かれ、全体図に母集団の項目と分けて書かれている
- [ ] 【骨子】付録を除く本文の最後に、最初と同じ全体図がある。全体図を分けたときは、総覧のページと区分ごとのページが同じ順である。最後の全体に、全体図の項目と、部分で述べた結論だけが載っている
- [ ] 最初と最後の全体図と現在地の縮小を、重なりとして直していない。最後の全体を、末尾のまとめとして消していない
- [ ] 【骨子】質問や依頼は、選んだ資料の種類で認められ、依頼者が必要としているときだけ載せている。載せるときは、最後の全体図の該当する項目に添えている

## スライドのページ

- [ ] 【骨子】判断を求める資料と説明の資料の部分のページでは、資料の題と部の名前を除き、1枚に結論が1つで、ページの題が結論の文になっている。手順書と設計の記録では、ページの題が作業か対象の名前になっている。例: 現在地の印に「案1 分量の自動計算」、題に「献立の人数を変えると、材料の分量が自動で変わります」
- [ ] 【骨子】答えを後のページに回すときは、どのページで答えるかを先に書いている
- [ ] 【骨子】項目を並べるページは、題に項目の数が入っている
- [ ] 【骨子】1枚の図と表が合わせて2つまで
- [ ] 【骨子】判断を求める資料と説明の資料では、本文の図、表、画面が、題の裏付けになっている。手順書の手順と期待結果、設計の記録の設定値は除く。裏付けにならないページと要素は、消すか、まとめるか、付録へ移した
- [ ] 【骨子】全部のページの題を順に書き出し、題だけで話の筋が通る。題の数とほぼ同じ数の文で、資料の筋を言える
- [ ] 【骨子】冒頭の一覧の各項目が、後のページの題と同じ順で対応している
- [ ] 画面の写真は、必要な部分だけを切り抜いている。説明の文と番号は、写真の該当する箇所の隣にある
- [ ] 引用した数値、図、画面に出典がある

## スライドの見た目

- [ ] 同じ情報が近く、違う情報が離れている。読む順が上から下、左から右で、要素が散っていない
- [ ] 並びの型が中身の種類に合い、資料の中で同じ型を繰り返している
- [ ] 色がベース、メイン、アクセントの3色程度で、アクセントの色は目立たせたい所だけ。見分けにくい色の組み合わせで区別していない
- [ ] 題、小見出し、本文の文字の大きさに、はっきり差がある。見せる資料の本文が28ポイント以上
- [ ] 資料の全体で、配置と色が同じ。中身に関係の無い飾り、ロゴ、画像が無い
