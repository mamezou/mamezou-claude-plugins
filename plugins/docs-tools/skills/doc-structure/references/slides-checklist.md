# スライドのチェックリスト

PowerPoint、Google スライド、Keynote、HTML や PDF のスライドなど、ページに分けた資料に使う。資料の種類のチェックリストと一緒に使い、種類の決まりを置き換えない。

種類の決まりの「章」は、スライドでは「部」と読み替える。部は、種類の一覧の項目1つに当たるページのまとまりで、決めること、問い、作業、対象のどれか1つに部を1つ作る。全体図には、母集団の各項目を、どの部で扱うかと一緒に書く。1つの部が、全体図の複数の項目を扱ってよい。

【骨子】の印の項目は、骨子を作った後と本文を書いた後の2回確認する。印の無い項目は、本文を書いた後に確認する。当てはまらない項目は「対象外」と理由を書き、確認できなかった項目は「未確認」と書く。決まりの根拠と出典は `principles.md` の「スライドに足す決まり」にある。

## 作る前

- [ ] 【骨子】見せる資料か配る資料かを1つに決めた。見せる資料は、人が話しながら映す。配る資料は、読み手が1人で読む。両方に使うときは、資料を2つに分けるか、配る資料の文をノートに書く
- [ ] 【骨子】依頼者が形式を決めていないときは、文書で足りないかを、手順7の骨子の確認と一緒に聞く。依頼者がスライドと決めているときは対象外
- [ ] 【骨子】全体図の母集団の正本の名前を、問いの一覧の正本とは分けて書いた。機能の説明なら、全部の機能を確かめられる要件定義か機能の一覧。計画の説明なら計画書

## 最初の全体

- [ ] 【骨子】表紙と目的のページの次に、全体図のページがある。目的のページには、資料の種類の冒頭の一覧を置く
- [ ] 【骨子】全体図に、母集団の全部の項目が載っている。各項目は、対象、対象外、行わない、のどれかで区別されている
- [ ] 【骨子】全体図の区分の切り口が1つで、名前を書ける。例: 時間の順で、準備、届いた日、当日、片付け
- [ ] 【骨子】読み手が知らない語は、全体図のページか、その前で説明している
- [ ] 全体図は1ページで見渡せる。入りきらないときは、区分だけを1ページに出し、区分ごとの中身を次のページに出す

## 部分

- [ ] 【骨子】種類の一覧の項目ごとに部が1つあり、全体図の対象の項目の全部が、どれかの部に入っている。部の順は全体図の順と同じ
- [ ] 【骨子】全体図の対象の各項目に、説明するページの番号がある。対応するページが無い項目が無い
- [ ] 【骨子】全体図に無いページが無い。番号の外の案、全体図に無い機能など。共通のページは、全体図に母集団の項目と分けて書いてあればよい
- [ ] 部分のページに、全体図の縮小と現在地の印がある。現在地の印に、部の呼び名と番号を書く。表紙、目的、全体図、共通、最後の全体のページは除く
- [ ] 部の呼び名と番号が、全体図の呼び名と番号と同じ

## 最後の全体

- [ ] 【骨子】最後のページが全体図に戻っている。部分で述べたことを、全体図の上にまとめている
- [ ] 【骨子】最後の全体に、部分のページに無い事柄と数値が無い
- [ ] 【骨子】質問や依頼は、選んだ資料の種類で認められ、依頼者が必要としているときだけ載せている。載せるときは、最後の全体図のページに、全体図の項目と結んで添えている

## ページの題

- [ ] 判断を求める資料と説明の資料では、1枚に結論が1つで、ページの題が結論の文になっている。例: 現在地の印に「案1 分量の自動計算」、題に「献立の人数を変えると、材料の分量が自動で変わります」
- [ ] 手順書と設計の記録では、ページの題が作業か対象の名前になっている
- [ ] 本文の図、表、画面の写真が、題の裏付けになっている。裏付けにならないものは消すか付録へ移す
- [ ] 全部のページの題を順に書き出し、題だけで話の筋が通る。途中で話題が跳ばない
- [ ] 冒頭に要約があるとき、要約の各項目が、後のページの題と同じ順で対応している

## 1枚の作り方

ページを作った後に確認する。構成の決まりではないが、スライドでは題の裏付けの読みやすさを左右するため、ここで見る。

- [ ] 画面の写真は、必要な部分だけを切り抜いている。説明の文と番号の丸は、写真の該当する箇所の隣に置いている
- [ ] 配る資料では、説明する人がいなくても、題と本文だけで結論が分かる。見せる資料では、文を詰め込んでいない
