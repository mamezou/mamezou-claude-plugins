# 経費精算システムのバックアップの検討

経費精算システムのバックアップについて、方式を整理し、対策を検討する。

判断が必要な事項は2つである。

- バックアップの方式
- 保持期間

## 1. 目的と背景

経費精算システムは、申請と承認のデータをデータベースに保存している。データベースの障害に備えて、バックアップの方式を検討する。

## 2. 現状

| 項目 | 内容 |
|---|---|
| バックアップ | 日次、保持は7日 |
| 月額 | 約3,000円 |

## 3. 対策

### 3-1. 方式の比較

| 方式 | 月額 | 失われるデータ |
|---|---|---|
| 日次 | 約3,000円 | 最大24時間分 |
| 継続 | 約9,000円 | 最大5分間 |

### 3-2. 推奨

推奨は継続のバックアップである。月額は約9,000円で、失われるデータは最大5分間になる。

### 3-3. 復元の手順と時間

| 方式 | 復元の時間 |
|---|---|
| 日次 | 約2時間 |
| 継続 | 約2時間 |

### 3-4. 保持期間

保持期間は7日と35日から選択できる。35日にすると月額は約12,000円になる。推奨は35日である。月末の締めの誤りに翌月に気付く場合があるためである。

### 3-5. 別の地域への複製

別の地域への複製は行わない案とする。

## 4. まとめ

| 項目 | 案 |
|---|---|
| バックアップの方式 | 継続。月額は約9,000円、失われるデータは最大5分間 |
| 保持期間 | 35日。月額は約12,000円 |

## 5. 参考情報

申請の添付ファイルは別のストレージにあり、この資料のバックアップの対象に含まれない。
